### 1️⃣ **FREESOUND.ORG** (⭐⭐⭐⭐⭐ RECOMENDADO)
🔗 https://freesound.org

**Por que é o melhor:**
- ✅ Maior banco de áudios gratuitos do mundo (600.000+ sons)
- ✅ Todos com licença Creative Commons
- ✅ Alta qualidade (até 320kbps MP3 / WAV)
- ✅ Sistema de tags muito bom
- ✅ Pode usar comercialmente (verificar licença de cada áudio)

**Como usar:**
1. Crie conta grátis em https://freesound.org/home/register/
2. Busque por:
   - **"rain ambience"** - Chuva relaxante
   - **"ocean waves"** - Ondas do mar
   - **"forest ambience"** - Sons da floresta
   - **"meditation bell"** - Sino tibetano
   - **"white noise"** - Ruído branco
   - **"fireplace crackling"** - Lareira crepitando
   - **"birds singing"** - Pássaros cantando
   - **"thunder distant"** - Trovão ao longe
3. Filtros úteis:
   - **Duration**: > 1 minute (para loops)
   - **License**: Creative Commons 0 (domínio público)
   - **Channels**: Stereo (melhor qualidade)
4. Clique em "Download" (formato MP3 ou WAV)

**Áudios recomendados**:
- Rain on Roof: https://freesound.org/search/?q=rain%20roof
- Ocean Waves: https://freesound.org/search/?q=ocean%20waves%20loop
- White Noise: https://freesound.org/search/?q=white%20noise

## 📝 CHECKLIST PARA ADICIONAR ÁUDIOS NO APP

### **Passo 1: Baixar os áudios**
- [ ] Baixar 8-12 áudios de diferentes categorias
- [ ] Verificar licença (Creative Commons 0 ou uso comercial permitido)
- [ ] Salvar informações de atribuição se necessário

### **Passo 2: Preparar os arquivos**
- [ ] Converter para MP3 (se estiver em WAV)
- [ ] Normalizar volume (usar Audacity grátis)
- [ ] Cortar silêncios do início/fim
- [ ] Renomear arquivos: `chuva_suave.mp3`, `ondas_mar.mp3`

### **Passo 3: Hospedar os áudios**

**OPÇÃO A - Google Drive (Fácil)**:
1. Upload dos MP3 para Google Drive
2. Compartilhar → "Qualquer pessoa com o link"
3. Copiar link compartilhado
4. Converter para link direto: https://sites.google.com/site/gdocs2direct/

**OPÇÃO B - Dropbox**:
1. Upload para Dropbox
2. Gerar link compartilhado
3. Mudar `?dl=0` para `?dl=1` no final do link

**OPÇÃO C - Armazenar no app (melhor para qualidade)**:
1. Criar pasta `app/src/main/res/raw/`
2. Copiar MP3s para essa pasta
3. Mudar código para usar `raw/nome_arquivo`

### **Passo 4: Atualizar Sound.kt**
1. Abrir `/app/src/main/java/com/calmare/app/data/Sound.kt`
2. Substituir URLs de exemplo pelos seus links
3. Atualizar títulos e descrições
4. Build e testar

## ⚖️ CONSIDERAÇÕES LEGAIS

### **Tipos de Licença Creative Commons:**

✅ **CC0 (Domínio Público)** - MELHOR para uso comercial
- Pode usar livremente
- Não precisa atribuir
- Pode modificar

✅ **CC BY (Atribuição)** - BOM para uso comercial
- Pode usar comercialmente
- Precisa dar crédito ao autor
- Exemplo: "Música por [Nome] (freesound.org)"

⚠️ **CC BY-NC (Não Comercial)** - NÃO USAR
- Proibido uso comercial
- Não serve para apps que geram receita

⚠️ **CC BY-ND (Sem Derivações)** - EVITAR
- Não pode modificar
- Limitante para apps
